# 제품 설명 — 공공 웹사이트 불법광고 탐지 도구

## 목적

공공기관 웹사이트 담당자가 주소 하나로 게시글·댓글·프레임의 불법광고 의심 내용을 찾고,
은폐 방식과 위치를 확인해 후속 조치에 사용할 근거를 남기는 Windows 도구다.

## 입력과 처리

- 한 사이트 주소 또는 CSV·XLSX·JSONL·XML 대상 목록을 입력한다.
- 동일 사이트의 페이지를 탐색하며 실제 브라우저의 DOM·CSS·기하 정보와 프레임을 분석한다.
- 원문·페이지 주소·요소 위치·화면 근거를 수집하고 확인한 페이지와 접근 실패를 함께 기록한다.
- 기본 점검 범위는 최대200페이지·하위4단계·25분이며 고급 모드에서 범위를 조절한다.

## 공식 탐지

광고 의미와 은폐 근거를 함께 분석한다. 정상 내비게이션·접근성 문구·공공 안내와 상품 광고를
구분하는 제외 규칙을 적용한다.

| 기법 | 분석 내용 |
| --- | --- |
| `HOMOGLYPH` | 전각·키릴·라틴 유사 문자와 문자열 난독화 |
| `JAMO` | 분리된 한글 자모의 복원과 광고 의미 |
| `TRANSPARENT` | 글자색·배경·alpha·조상 clipping에 의한 은폐 |
| `OFFSCREEN` | 화면 밖 배치·overflow 등 기하적 은폐 |

정규화 이전 원문을 보존한다. CSS 선택자의 유일성과 왕복을 확인하고 iframe 내부 위치는
`iframe[...] >>> selector`로 표시한다.

## 추가 분석

이미지 광고는 OCR, 광고 문맥 규칙, 로컬 문자·이미지 임베딩으로 분석한다. 이미지형 광고,
재사용 광고 이미지, 인프라 연관 단서, 영폭 문자 난독화는 추가 결과로 제공한다.
이미지에서는 최대32후보를 수집하고 서로 다른 OCR 입력은 전체40개로 제한한다.
GIF는 최대120프레임을 관찰해 최대4프레임을 보존한다.

## 결과와 검토

| 파일 | 내용 |
| --- | --- |
| `result.json` | 네 공식 기법의 탐지, 원문, URL, 위치, 판정 |
| `result_extra.json` | 이미지 광고 등 추가 분석 |
| `review.json` | 공식 탐지별 담당자 판단·메모·검토 상태 |
| XLSX | 요약, 탐지 상세, 확인 범위, 추가 분석, 검토 기록; 여러 대상이면 대상 요약 추가 |

화면은 점검 설정 → 사이트 점검 → 결과 검토로 구성한다. 간단·고급 모드는 동일한 엔진과
사례 저장소를 사용한다. 저장된 사례를 다시 열어 검토를 이어가고 보고서를 다시 생성할 수 있다.
원문과 메모는 Excel의 문자열 셀로 기록한다.

## 구현

| 구성 | 역할 |
| --- | --- |
| React·TypeScript | 한국어 점검·검토 화면 |
| Playwright·Chromium | 실제 페이지·프레임 수집, 위치 검증 |
| 탐지 엔진 | 광고 의미·문자·스타일·기하 판정 |
| CPU OCR·ONNX Runtime | 한국어 이미지 문자와 로컬 임베딩 분석 |
| Tauri·Rust | Windows 실행, 프로세스 수명, 사례·검토 저장, 파일 내보내기 |

페이지 작업자는 최대4개이며 하나의 점검 마감 시간을 공유한다. 공식 결과를 먼저 저장하고
추가 분석을 수행한다. 모델은 해시로 고정해 설치 파일에 포함하며 점검 중 내려받지 않는다.
사례는 사용자 AppData에 저장한다.
