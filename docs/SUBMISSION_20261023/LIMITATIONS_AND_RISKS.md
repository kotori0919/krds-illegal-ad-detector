# 기능 지원 범위

## 점검과 결과

| 항목 | 범위 |
| --- | --- |
| 실행 환경 | Windows11 x64, CPU 추론, WebView2 |
| 공식 탐지 | HOMOGLYPH·JAMO·TRANSPARENT·OFFSCREEN |
| 추가 분석 | 이미지형 광고, 재사용 이미지, 인프라 연관 단서, 영폭 문자 난독화 |
| 기본 사이트 점검 | 최대200페이지·하위4단계·25분, 동일 사이트 탐색 |
| 이미지 분석 | 문서당32후보, 이미지 수집 최대8페이지, 전체 OCR40입력 |
| GIF | 최대120프레임 관찰·4프레임 보존 |
| 담당자 검토 | 공식 탐지별 판단·메모·검토 상태 저장 |
| 일괄 점검 | 대상별 순차 점검·사례 저장·그룹 복원·통합 XLSX |

APNG·애니메이션 WebP·동영상 분석과 추가 분석 항목의 영구 검토 기록은 지원 범위에 포함하지 않는다.

## 분석 특성

- OCR은 축소·저해상도·흐린 글자·로고형 표현을 놓칠 수 있다.
- GIF는 제한된 프레임을 선택하며 이미지·텍스트·시간 예산에 도달하면 부분 분석으로 기록한다.
- 로컬 임베딩은 OCR과 광고 문맥을 보강하며 일반 상품·공공 안내를 제외하는 규칙을 함께 적용한다.
- 로그인·접근 제한·외부 호스트 이동·시간 초과는 페이지별 확인 범위에 기록한다.
- CPU 부하와 모델 초기화는 추가 이미지 분석 시간에 영향을 준다.

공식 JSON에는 네 기법의 결과를 저장하고 이미지 광고 등 추가 분석은 별도 JSON에 저장한다.
공식 원문과 담당자의 판단·메모도 분리 보관한다.
