# 원본·검토·진단 데이터 처리

공식 원본은 `result.json`, 추가 탐지는 `result_extra.json`, 검토 기록은
`review.json`으로 분리한다. 원본은 재열기·판단·메모·보고서 생성으로 변경하지
않는다. 새 검사의 policy 3 결과가 과거 결과와 달라질 수 있으며 재검사는 새
case ID를 사용한다. schema/config/policy 규칙은 CONTRACTS.md가 기준이다.

Windows 보관 위치는 `%APPDATA%\kr.go.nia.illegal-ad-detector\cases`다.
사용자 프로필의 권한을 상속하며 앱 자체 암호화를 제공하지 않는다. 조직은
단말 암호화·계정 권한·보존 기간·백업 위치를 정한다. 자동 만료나 자동 삭제는
없다. 사건 삭제는 해당 사건의 로컬 원본·자산·메모를 제거하지만 별도로
내보낸 복사본은 제거하지 않는다. 백업/복구는 앱을 닫고 운영 가이드의
관리 스크립트를 사용한다. `.store.lock`은 프로세스 종료 시 OS가 해제한다.

비정상 종료의 `.pending-*`/`.import-*`는 다음 시작에서 `.quarantine-*`로
격리하고 목록에 `QUARANTINED_TRANSACTION`을 표시한다. 원문은 보존한다.
격리 폴더를 새 사건으로 이름만 바꾸지 않는다. 관리자는 백업한 뒤 유효한
`result.json`을 공식 검증기로 확인하고 복구 가능한 파일을 따로 전달한다.
완료 manifest가 없는 자료에 검사가 완료되었다는 메타데이터를 만들어 넣지
않는다. 권한·디스크 부족으로 저장 실패 시 앱 오류에 표시된 임시 결과도
보존되며 원인을 해결하기 전 삭제하지 않는다.

전달 폴더는 버전·원본 해시·파일 허용 목록·크기·이미지 형식·링크/재분석
지점·검토 참조를 검사한다. 원문 HTML, 실행 파일, 임의 경로, 미래 schema를
실행하거나 자동 변환하지 않는다. 근거 자산이 없거나 손상되면 미확인으로
표시하고 원격에서 다시 내려받지 않는다. 전달은 대상·권한·보존 정책을 확인한
운영자가 수행한다. 앱은 원본이나 진단을 외부로 자동 전송하지 않는다.

앱 전용 WARP는 사용자의 명시적인 약관 동의와 등록 실행 후에만 Cloudflare에
장치를 등록한다. 등록 자격 정보는 앱 데이터의 `warp/config.json`에 평문으로
저장하며 폴더와 파일의 Windows ACL은 현재 사용자와 SYSTEM으로 제한한다.
동일 사용자 프로세스나 관리자에 대한 격리·앱 자체 암호화·디스크 암호화를
제공하지 않는다. Case 전달 폴더와 공식 JSON에는 자격 정보·프록시 인증 정보·
원문 등록 출력이 포함되지 않는다. 공식 WARP 클라이언트의 키나 설정은 읽지
않으며 시스템 DNS·전역 경로를 변경하지 않는다.

일반 점검은 현재 PC 네트워크로 대상 사이트에 접속하며 앱 전용 WARP가 필수가 아니다. 사용자가 고급 모드에서 WARP를 선택한 경우에만 등록·연결 확인용 외부 통신이 필요하다. 연결
실패 시 직접 전송으로 전환하지 않으며, 저장된 Case 열기·검토·내보내기는
오프라인에서도 가능하다. Case의 제한된 `transport`에는 WARP 백엔드/버전 또는
기본 연결의 일반 UI 출처(operator), CLI 또는 허용 원점의 직접 평가 여부만 기록한다. 선택한 방식은 settings.connection에 별도 기록한다. 연결 실패는 `transportFailure`의
제한된 코드와 `incomplete` 범위로 저장하고 실패한 Case를 미완료로 표시한다.
과거 Case에 없는 연결 정보를 만들지 않으며 공식 결과 형식이나 탐지 정확도를
바꾸는 정보가 아니다. 등록 완료가 불확실하면 자동 재등록하지 않고 담당자가
장치와 설정 저장 상태를 확인한다. 실패 기록을 임의로 삭제하여 반복 등록하지
않는다. 자세한 운영 절차는 [WARP 등록 안내](WARP_REGISTRATION.md)를 따른다.

배너 OCR은 선택한 이미지 bytes를 로컬 자식 프로세스에서 처리한다. Tesseract의
낮은 신뢰도 PNG에는 PP-OCRv5 한국어 CPU 모델을 사용한다. 점검 중 외부 AI 호출이나
모델 다운로드는 없다. 빌드 최초 준비에서는 고정 URL·크기·SHA-256으로 모델을
가져오며 언어 데이터·모델·라이선스를 결과 패키지에 포함한다. GIF에서 선택된
프레임은 기존 이미지 보관 범위에 포함하고 프레임 번호·시각을 상세 근거에 기록한다.
EmbeddingGemma 2의 고정 텍스트·이미지 참조와 로컬 CPU 임베딩 비교는 현재 점검의 추가 분석 경로에 포함된다. 공식4기법 판정과 별도로 취급하며 법적 위반 확정이 아니다. 모델 오류·제한으로 분석이 완료되지 않은 경우 이를 확인해야 한다. 출처·고정 revision·SHA·라이선스는 [데이터 출처 인덱스](DATA_PROVENANCE_KO.md)를 따른다.

진단 미리보기는 버전·저장 경로·네트워크 정책·선택적 VLM off·서명 상태만 다룬다.
사용자명이 포함된 경로는 공유 전 검토/삭제한다. 일반 로그에 원문·메모·토큰을
추가하지 않는다. XLSX의 원문/메모는 문자열 셀로 기록하며 수식·외부 링크로
해석하지 않는다. 실제 Excel 및 보조기기 판독은 후보별 외부 수용 사항이다.

일반 오류의 기존 연락 경로는 [저장소 Issues](https://github.com/snowman0919/krds-illegal-ad-detector/issues)다. 공개 issue에는 원문·메모·개인정보·토큰·사용자 프로필 경로를 넣지 않는다. 민감한 보안 사건의 비공개 접수 담당자와 조직 내부 경로는 수신 조직이 지정해야 하며 현재 문서는 존재하지 않는 연락처를 만들지 않는다.
