# 사용자 매뉴얼

## 이 도구는 무엇인가요

공공 웹사이트의 숨겨진 불법광고를 검사하는 도구입니다. 시작 주소 하나를
입력하면 관련 하위 페이지를 수집하고, 게시글·댓글·iframe 내용을 검사하여
4가지 공식 은폐 기법(HOMOGLYPH, JAMO, TRANSPARENT, OFFSCREEN)을 판별합니다.

## 사용 순서

1. **탐지 시작**: 검사할 웹사이트 첫 주소를 입력하고 [탐지 시작]을 누릅니다.
   고급 설정에서 최대 페이지 수·탐색 깊이·제한 시간을 조절할 수 있습니다.
2. **탐지 진행**: 실제 개수로 진행 상황을 확인합니다 (백분율 아님).
   [탐지 취소]로 언제든 중단할 수 있습니다.
3. **탐지 결과**: 기법별 건수와 목록을 확인하고, 필터로 좁히고, [근거 보기]로
   이동하거나 [검증 및 내보내기]로 이동합니다.
4. **탐지 근거**: 관찰된 증거(원문·위치·기법), 도출된 정보, 추론을 구분해서
   보여줍니다. 추론은 관찰이 아닙니다.
5. **결과 검증 / 내보내기**: 6개 검증이 모두 통과해야 [result.json 저장]이
   활성화됩니다.

## 결과 파일

- `result.json`: 공식 제출 파일 (4종 기법만).
- `result_extra.json`: 확장 탐지 (ETC + 종류 표기, 별도 검증).

## 주의사항

- 외부 광고 사이트는 직접 방문하지 않고 관측만 합니다.
- 평범한 숨김 UI(접근성 텍스트, 닫힌 메뉴·대화상자)는 탐지하지 않습니다.
- 공식 제한 30분 안에 끝나도록 기본 제한(1500초)이 설정되어 있습니다.
