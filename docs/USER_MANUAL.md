# 사용자 매뉴얼 — 현재 빌드 안내

2026-10-05 기준 이 문서는 **현재 실행되는 5단계 UI**를 설명합니다. NIA 운영자를 위한
3단계 Product V2 화면은 `PRODUCT_SPEC.md`/`SCREEN_SPEC.md`에 설계되어 있으며 아직
코드에 적용되지 않았습니다. 브라우저 미리보기는 데모 결과를 보여주며 실제 사이트
점검은 Windows 데스크톱 앱에서 합니다.

## 현재 사용 순서

1. **탐지 시작**: 시작 주소를 입력하고 [탐지 시작]을 누릅니다. 고급 설정에서
   최대 페이지 수·탐색 깊이·제한 시간을 바꿀 수 있습니다.
2. **탐지 진행**: 방문·대기 페이지 수와 탐지 수를 확인합니다. [탐지 취소]를
   누르면 실행이 중지되고 시작 화면으로 돌아갑니다. 현재 빌드는 중지 전 결과를
   저장할 수 있다고 보장하지 않습니다.
3. **탐지 결과**: 기법별 건수와 목록을 확인하고 필터를 선택합니다. 현재 목록의
   `위치`는 CSS 선택자이며 Product V2에서 기술 정보로 옮길 예정입니다.
4. **탐지 근거**: 목록의 [근거 보기]로 이동하여 원문, 페이지, 위치를 봅니다.
   현재 빌드는 실제 스캔 스크린샷과 자세한 자연어 설명을 제공하지 않습니다.
5. **결과 검증 / 내보내기**: 6개 검증 상태를 확인하고 [result.json 저장]을
   누릅니다. 파일 선택을 취소하면 결과는 그대로 남습니다.

## 결과 파일과 해석

`result.json`은 네 가지 공식 기법(HOMOGLYPH, JAMO, TRANSPARENT, OFFSCREEN)의
탐지 결과입니다. `result_extra.json`은 별도 확장 분석 결과입니다. 탐지가 0건이어도
사이트 전체에 문제가 없다는 보장은 아닙니다. 현재 빌드는 실패한 페이지의 목록과
부분 점검 범위를 결과 화면에 보존하지 않으므로 업무 판단 시 이 한계를 고려해야
합니다. 외부 광고 목적지는 자동으로 열지 않습니다.

## 다음 화면 설계

Product V2는 점검 설정 → 사이트 점검 → 결과 검토로 구성하고, 결과 화면 안에서
탐지 항목별·페이지별 검토, 근거 패널, 실패 페이지 목록, 결과 저장을 제공합니다.
현재 기능과 혼동하지 않도록 구현 뒤 이 매뉴얼을 실제 화면에 맞춰 다시 작성합니다.
