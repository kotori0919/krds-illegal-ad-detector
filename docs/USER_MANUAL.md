# 사용자 매뉴얼

Windows 데스크톱 앱의 점검·근거 검토·저장 절차를 설명합니다.

**저장 위치부터 확인하세요.** 점검 완료 후 고급 모드의 결과 상단 **보관 정보**를 열면 실제
저장 폴더와 공식 원본의 전체 경로가 표시됩니다. Windows 기본 위치는
`%APPDATA%\kr.go.nia.illegal-ad-detector\cases\<케이스 번호>\result.json`입니다.
표시된 실제 경로를 우선합니다. `result_extra.json`은 같은 케이스의 추가 분석이며
공식 결과와 구분됩니다. 설치 폴더와 사용자 케이스 폴더는 별개입니다.

## 설치와 제거

`불법광고 탐지 도구_0.2.1_x64-setup.exe`를 실행해 설치합니다. Windows 11 일반 사용자로
설치·실행하며 Node, 개발 저장소, 별도의 Playwright·OCR 모델 준비는 필요하지 않습니다.
WebView2 Runtime이 없으면 설치 관리자가 내려받으므로 인터넷 연결이 필요합니다.
설치 파일의 식별 정보는 [제출 파일 식별](SUBMISSION_20261023/EVIDENCE_INDEX.md)을 따릅니다.

제거할 때는 앱을 정상 종료한 뒤 Windows의 설치된 앱 목록을 사용합니다. 저장 사례와
내보낸 파일은 설치 폴더와 별도로 관리합니다.

## 현재 사용 순서

첫 실행에서 **간단 모드** 또는 **고급 모드**를 고릅니다. 기본 선택은 간단 모드이며
상단의 **화면 모드**에서 변경할 수 있습니다. 선택 저장에 실패하면 이번 실행에
적용하고 다음 실행에 다시 선택하도록 안내합니다. 두 모드는 같은 탐지 결과와
검토 기록을 사용합니다. 모드 전환은 새 점검을 실행하지 않습니다.

일반 점검은 **기본 연결**로 현재 PC 네트워크를 사용합니다. 앱 전용 WARP 등록이나
구성 요소가 없어도 점검할 수 있습니다. PC 자체 VPN·프록시 상태를 해제하거나
확인했다는 뜻은 아닙니다. 기본 연결 실패 시 WARP로 자동 전환하지 않습니다.

### 간단 모드

1. **새 점검**: 사이트 주소와 최대 200페이지·하위4단계·25분 범위를 확인하고
   **점검 시작**을 누릅니다. 입력한 사이트의 하위 페이지·게시글·댓글·프레임을 확인합니다.
2. **사이트 점검**: 경과 시간·확인 페이지·탐지·실패 수를 봅니다. **점검 중지**를
   확인하면 종료 정리를 기다린 뒤 보관된 부분 결과를 검토합니다.
3. **결과 검토**: **의심 항목**에서 문구·페이지를 검색하고 검토 상태로 좁힙니다.
   **근거 보기**에서 원문·촬영 근거와 이유를 보고 판단·메모를 입력합니다.
   **검토 완료·다음**은 저장 완료 후 다음 항목으로 이동합니다. 읽음 완료는 위반 확정이 아닙니다.
4. **보고서 저장**: **엑셀 보고서 저장**은 검토 기록을 저장·재조회한 뒤 전체 결과로
   생성합니다. 저장 실패를 해결하지 못하면 누락된 검토로 보고서를 만들지 않습니다.
   **결과 파일 → 공식 JSON 저장**에서 평가용 결과도 저장할 수 있습니다.

기본 탐지와 **추가 단서**는 구분합니다. 기본 탐지0건이어도 이미지 등 추가 단서가
있을 수 있습니다. 추가 단서는 근거 조회용이며 현재 판단·메모 편집은 기본 탐지만
지원합니다. **점검 범위**에서 실패·시간 초과와 수집·이미지 분석 제한을 확인하세요.
미방문 페이지 전체 수를 모르는 경우 사이트 전체가 확인됐다고 해석하지 않습니다.

### 고급 모드

**상세 설정**에서 자동(200페이지·4단계·25분), 빠른(50페이지·2단계·10분),
직접 설정을 선택합니다. 직접 설정의 제한 시간은 60~1500초입니다.
**여러 사이트 일괄 점검**은 CSV·XLSX·JSONL·XML 대상을 미리 확인한 뒤 사이트별로
순차 점검합니다. 입력한 페이지만 점검하면 대상별1페이지·깊이0·최대1분입니다.
대상마다 공식 결과를 따로 보관하며 하나의 공식 JSON으로 합치지 않습니다.
일괄 작업 묶음은 대상·순서·사례 식별자·진행 상태를 함께 저장하므로 앱을 다시
시작한 뒤에도 **이전 일괄 점검 묶음** 목록에서 복원할 수 있습니다. 복원은 저장된
결과만 읽고 사이트에 다시 접속하지 않으며, 남은 대상은 이어서 점검할 수 있습니다.
완료된 대상의 저장된 검토 판단·메모를 포함한 통합 엑셀을 다시 만들 수 있고,
점검을 마치지 못한 대상은 미완료로 표시되어 완료로 계산되지 않습니다.

결과에서는 페이지별·반복 항목별 보기, 기법 필터, 기술 정보와 OCR 기록을 확인할
수 있습니다. **인프라 분석**은 현재 결과 또는 선택한 저장 사례 한 개의 광고 연관
도메인을 검색하고 반복 관측·근거 종류로 좁힙니다. **근거 확인 → 관계 보기**에서
관련 페이지와 원본 기록을 읽습니다. 일반 외부 자료 호스트를 불법 인프라로
단정하지 않으며 공동 운영자를 추정하지 않습니다. 여러 사례 통합과 새 외부 사이트를
따라가는 능동 탐색은 제공하지 않습니다.

### 선택형 앱 전용 WARP

고급 모드의 **설정·도움말**에서 약관을 읽고 명시적으로 동의한 뒤 등록할 수 있습니다.
상태 조회·앱 시작·점검 시작은 등록하지 않습니다. **저장된 설정 확인 완료**는 활성
연결이 아닙니다. 상세 설정에서 **앱 전용 WARP**를 선택하고 점검을 시작해야 해당
세션에서 터널을 준비합니다. 준비 시간도 점검 제한 시간에 포함됩니다.

선택은 해당 점검/일괄 작업에만 적용하며 **새 점검**이나 새 대상 파일은 기본 연결로
시작합니다. 설정에서 **현재 작업으로 돌아가기**는 아직 시작하지 않은 초안의 선택을
유지합니다. 연결 실패 시 기본 연결로 자동 전환하거나 자동 재등록하지 않습니다.
필요하면 사용자가 다른 방식을 선택해 새 점검을 시작하고 이전 결과를 보존합니다.
공식 WARP 클라이언트·시스템 DNS·전역 경로는 변경하지 않습니다.
등록의 불확실한 결과나 권한·무결성 오류는 [WARP 등록 안내](WARP_REGISTRATION.md)를
따라 담당자에게 확인하고 반복 등록하지 않습니다.

**저장된 결과**는 상단 업무 메뉴에서 엽니다. 사례 재열기·검토와 인프라 조회는
사이트를 다시 방문하지 않으며 WARP 등록 없이 사용할 수 있습니다. 실패 사례의
보관된 유효 결과도 검토할 수 있습니다. 이전 Case에 없는 연결 정보는 추정하지 않습니다.

## 결과 파일과 해석

`result.json`은 네 가지 공식 기법(HOMOGLYPH, JAMO, TRANSPARENT, OFFSCREEN)의
탐지 결과입니다. 추가 분석은 공식 결과에 합산하지 않습니다. 탐지가 0건이어도
사이트 전체에 문제가 없다는 보장은 아닙니다. 실패한 페이지와 제한 시간 도달 여부는
[점검 범위]에서 확인합니다. 외부 광고 목적지는 자동으로 열지 않습니다.

## 보관·다시 열기·담당자 판단

상단 **저장된 결과**의 **저장된 케이스**에서 이전 점검의 주소·시각·원본 탐지 수를
확인하고 **케이스 다시 열기**를 누릅니다. 저장된 원본과 근거를 읽으며 사이트를
다시 방문하거나 새 점검을 시작하지 않습니다. 일부 캡처·추가 분석이 없더라도
유효한 공식 결과는 계속 열 수 있으며 없는 근거는 사용 제한으로 표시됩니다.

**검토 완료**는 읽음 상태입니다. 상세의 **담당자의 판단**은 판단 전·위반 의심·
정상으로 판단·추가 근거 필요 중에서 별도로 선택합니다. **검토 메모**에는 직접
작성한 내용을 보관합니다. 이 세 가지는 원본 탐지 결과를 바꾸지 않습니다.
변경하면 자동 저장하며, 결과 상단의 **검토 기록 저장됨**을 확인한 뒤 종료하세요.
저장 대기 중 앱을 강제 종료한 수정은 보관되지 않을 수 있습니다.

저장 오류나 다른 창과의 수정 충돌이 나면 작성 중인 메모를 화면에 유지합니다.
권한·남은 공간을 확인한 후 **현재 메모를 유지하고 저장 재시도**를 누릅니다.
다른 창의 최신 기록을 읽되 현재 수정한 항목의 메모·판단을 우선 저장합니다.
같은 항목을 여러 창에서 동시에 수정하지 않는 것이 좋습니다. 브라우저
미리보기에서는 영구 보관을 지원하지 않으며 이 상태를 명시합니다.

**엑셀 보고서 저장**은 검색·필터와 관계없이 전체 원본 기록, 점검 범위, 사람의
읽음 상태·판단·메모와 케이스 번호·정책 버전·저장된 수정 번호를 담습니다.
주소와 메모는 텍스트로 보관하고 수식·활성 링크로 실행하지 않습니다. 보고서를
만들기 전에 검토 기록 저장 완료를 확인하세요.

## 전달·백업·삭제·진단

**전달 폴더 저장**은 선택한 케이스를 다른 폴더로 복사합니다. 받는 담당자는
**전달 케이스 가져오기**에서 해당 케이스 폴더를 선택합니다. 가져오기는 공식
원본과 내부 형식을 검사하고 경로 탈출·심볼릭 링크·실행 파일 등 지원하지 않는
내용을 거부합니다. 전달받은 HTML을 앱 안에서 실행하거나 누락된 근거를 인터넷에서
자동 다운로드하지 않습니다. 다른 팀에 전달하기 전에 원문에 개인정보가 있는지
담당자가 확인하세요. 기관 보존 기간을 앱이 임의로 정하지 않습니다.

업그레이드 전에는 필요한 케이스를 전달 폴더로 백업합니다. 복원은 가져오기로
실행하고 케이스를 다시 열어 원본 수와 검토 메모를 확인합니다. 새 형식을 이전
앱이 읽지 못할 수 있으므로 되돌리기 전에 호환성과 백업을 확인하세요. 정상
제거와 케이스 삭제는 다릅니다. **케이스 삭제**는 주소·케이스 번호·원본 수와
삭제되는 근거·판단·메모를 확인한 뒤 실행하며 앱에서 되돌릴 수 없습니다.
별도로 저장한 전달·백업 폴더는 유지됩니다.

**설치 진단 미리보기**는 도구·정책·케이스 형식 버전과 보관 위치 등을 화면에
보여 줍니다. 원문·쿠키·인증정보를 포함하지 않습니다. 경로의 사용자명 등은
전달 전에 확인하고 **확인한 진단 내용 복사**로 필요한 경우에만 전달하세요.
진단이나 발견 내용을 자동으로 외부 기관·서비스에 전송하지 않습니다.

## 이미지 분석 범위

OCR은 선택한 광고 이미지에 대한 한국어·영어 CPU 문자 인식입니다. 이미지 수집은
최대 8페이지, 문서당 32후보·1,000,000바이트, 개별 원본/변환 이미지
250,000바이트, 서로 다른 OCR 이미지 최대 40개로 제한됩니다. 전체 보관 한도와
점검 제한 시간도 적용되므로 40개의 인식 완료를 보장하지 않습니다.
GIF는 최대 120프레임을 살펴 중복을 제외한 최대 4프레임을 선택합니다.
앞·중간·뒤 구간에 분석 장면을 분산합니다. 분석 기록의 프레임 번호·시각과 부분
분석 안내를 확인하세요. 읽은 장면 중 선택하지 못한 내용도 있을 수 있습니다. 큰 파일, 선택되지
않은 프레임, APNG·애니메이션 WebP·동영상은 이 GIF 분석으로 확인되지 않습니다.
흐린 PNG 배너에는 추가 한국어 CPU OCR을 사용하며 이미지와 문자를 외부 AI로
보내지 않습니다. 모델은 빌드/패키지에 포함하고 점검 중 내려받지 않습니다.
기존 규칙으로 판단하지 못한 외부 연결 배너에는 인식한 문자의 의미를 로컬 모델로
보조 비교합니다. 공공 신고·예방 안내는 제외합니다. 이 결과는 ‘검토 필요’ 후보이며
글자를 새로 읽어낸 결과나 법적 위반 확정이 아닙니다. 원문과 실제 광고 내용을
확인하세요. 고급 정보에는 비교 점수·모델·처리 시간이 표시됩니다. 작은 배너에서는
다른 배율의 문자 인식 결과를 추가 비교할 수 있습니다. 고급 정보에서 선택한 원문과
다른 원문·엔진·실패 사유를 구분해 확인하세요. 모델 오류나
시간 제한이 있으면 보조 비교 불가 사유를 표시하고 기존 결과를 보존합니다.
페이지 확인 완료가 모든 이미지 분석 완료를 뜻하지 않습니다. 전체 후보 수가
알 수 없거나 제한으로 제외된 경우 화면의 점검 범위를 확인하세요. 선택적 학습
VLM은 비활성화되어 있습니다. 새 케이스의 검토 상태·판단·메모는 공식 원본과
분리해 저장됩니다.
