# 기획서 (신청서 지원 자료 초안; Product V2 설계 반영 중)

2026-10-05 기준: 탐지 엔진과 합성 사이트의 Windows 실행 근거는 있으나,
아래 운영자 중심 결과 검토 화면과 실제 사이트 시나리오 검증은 아직 구현·완료되지
않았습니다. 제품 완성 또는 대회 제출 준비 완료를 뜻하지 않습니다.

## 1. 배경과 문제

공공 웹사이트는 시민 신뢰의 창구이지만, 숨겨진 불법광고(도박·불법대출·
현금화 등)가 은폐 기법으로 숨어들어 공익을 해칩니다. 육안 점검은 숨김
요소를 찾기 어렵고, 외주 점검은 비용과 주기 한계가 있습니다.

## 2. 목적

누구나 실행할 수 있는 Windows 11용 탐지 도구를 제공합니다: 시작 URL 하나로
관련 페이지를 수집하고, 4가지 공식 은폐 기법을 판별하고, 근거와 함께
`result.json`을 생성합니다.

## 3. 데이터와 기술

- 데이터: 로컬 결정적 평가 사이트(22 케이스, 15 판정쌍) + 적대적 케이스(8 공격).
- 크롤러: Playwright API, 동일 사이트 BFS, 중복 제거, hostile-page 가드.
- 탐지: 의미 게이트(광고 어휘) AND 기법 신호(유니코드/계산 스타일/기하)의
  2축 판정. 값비싼 추론(OCR/VLM)은 후보에만, 기본 비활성화.
- 위치: 결정적 선택자 생성기 + iframe `>>>` 직렬화 + 유일성 검증.
- UI 목표: React + KRDS 기반 3단계 (점검 설정/사이트 점검/결과 검토).
  근거 확인·내보내기는 결과 화면의 동작입니다. 현재 코드에는 기존 5단계 UI가 있습니다.
- 데스크톱: Tauri 2 얇은 호스트 + Node 스캐너 사이드카 + Windows Job 정리.

## 4. 아키텍처

React → HostBridge → (Browser 미리보기 | Tauri 호스트 → 사이드카 →
Playwright → 탐지 파이프라인 → 결과 엔진). 내부 계약 v0.2 설계 중, `result.json`은
4종 기법만, 확장은 `result_extra.json`(ETC).

## 5. 구현

- 의미 게이트 + 4 탐지기 + 선택자 엔진 + 검증 결과 엔진.
- 증거 그래프(인프라 관측), 크리에이티브 지문(pHash 계열), 3종 확장 탐지.
- 적대적 대응: 구두점 분리·leet 치환 정규화, 혼합 자모 검출, 조상 투명도.

## 6. 사용자 흐름

점검 설정 → 사이트 점검(실제 개수·실패·중지) → 결과 검토(탐지 항목별/페이지별,
근거 패널, 범위·추가 분석, 파일 저장). 키보드 동선과 반응형 화면은 Product V2에서
재검증합니다.

## 7. 증거·결과 관리 UI

목표는 탐지마다 원문·페이지·자연어 설명·실제 촬영 근거를 우선 보여주고,
선택자·iframe 경로·CSS·기하는 기술 정보로 접는 것입니다. 현재 근거 화면은
공식 결과의 원문·선택자만 읽으며 실제 촬영 근거 파이프라인은 미구현입니다.
공식 결과의 스키마·중복·필수값 검증 및 저장 기능은 기존 코드를 재사용합니다.

## 8. 실제 배포

목표 환경은 Windows 11, GPU 없는 일반 PC입니다. 개발기 합성 사이트 14쪽의
44초 기록과 Windows 패키지 실행 근거는 `PERF.md`/`DRY_RUN.md`에 있습니다.
현재 빌드의 깨끗한 PC 설치·NSIS 수용 검사는 아직 끝나지 않았습니다.

## 9. 기대 행정 효과

정기 점검 자동화, 은폐 광고 조기 발견, 근거 기반 시정 요청, 외주 점검
보완으로 민원·신뢰 리스크 감소.

## 10. 독창성

- 2축 판정으로 숨김 UI 오탐을 줄이도록 설계; 복잡한 정상 사이트의 0건
  시나리오 검증은 아직 필요합니다.
- 선택자 유일성 게이트 + iframe 직렬화.
- 확장 인텔리전스(재사용 크리에이티브·인프라 상관·제로폭)를 공식 점수와 분리.
- 적대적 케이스 기반 내성 입증.

## 11. 확장 탐지

`result_extra.json`: REUSED_AD_CREATIVE, AD_INFRASTRUCTURE_CORRELATION,
ZERO_WIDTH_OBFUSCATION. OCR/VLM 슬롯은 벤치마크 후 확장 가능.
