# 작은 배너 누락·오탐 보정 검증 — 2026-10-21

기존 우주선·WINNER·MACHUJA3개는 일반 점검의 **이미지 기반 검토 후보**로 회복했다.
실제 문자를 복구했다고 주장하지 않는다. 기존 평가 양성46→49/49를 보존하면서 새로
드러난 교육 쿠폰·게임 교환코드·축소 학교 광고의 오탐도 보정했다. 그러나 새로운
저해상도 양성6개는 여전히4/6이며 파생 GIF1개도 누락된다. 전체 탐지 누락 해결이나
현장 정밀도100%, Windows/제출 준비 완료를 선언하지 않는다.

## 구현과 원인

`packages/detection/src/scan.ts`의 공식 결과 확정 → 기본 OCR → 기존 문자 의미 비교와
OCR 검증 → 조건부 이미지 비교 순서에 통합했다. 기존 직접 문구 양성, 공공안내/같은
화면 본문 제외, 공식 JSON은 유지한다. 이미 확정한 공식 JSON을 추가 분석이 덮어쓰지
않으며 별도 extra 검토 후보만 만든다. `textEmbedding: disabled`는 이미지 보조도 끈다.

온카는 검증용 PP가 Tesseract 원문의 유일한 `카지노` 범주를 잃고도 원문을 덮어썼다.
기존 범주 판별식을 공유해 그 정보 손실을 막았다. 공공안내/DOM 제외는 우선한다.
실제 원문과 margin 약0.030738을 보존하며, 손상 원문의 약0.000018 양성을 정당화하지 않는다.

교육 쿠폰은 OCR의 `수경합연부폰`/`추가입연부론` 같은 오독에서 수강 문맥을 잃었다.
후자의 `가입` 부분 문자열이 권유로 해석되기도 했다. 경품·추첨·당첨·상금만 관찰되고
실제 범주나 명확한 회원가입/가입코드/입금/충전/롤링 등의 문맥이 없으면 문자 유사도만으로
승격하지 않는다. 공식 semanticGate의 규칙을 바꾸거나 업종을 일괄 면제하지 않았다.

게임 교환코드는 실제 OCR이 `프로필 테두리 보상 획득 가능`을 정확히 읽었지만 기존
대조 설명이 아이템 교환권 유형을 충분히 나타내지 못했다. 고정 임계값0/기존 양성8개를
유지하고 일반 게임의 프로필·꾸미기 보상 코드 설명 하나를 추가한 `text-ad-embedding-v3`
(전체20참조)로 보정했다. 기존 v1/v2 저장 근거도 TS/Rust가 계속 읽는다. 실제 도박
광고에 아이템 문구를 붙인 반례는 양성을 유지한다. 브랜드 허용 목록이나 수동 전사는 없다.

작은 학교 홍보물은 축소 후 `MEXX`라는 이름만 읽고 문자 유사도로 통과했다. 의미 있는
광고 단서가 없는 한 단어만으로는 승격하지 않는다. 이 수정만으로는 `MEXX\nN`이 이미지
경로에서 재승격돼, 이미지 보조에도 **선택/미선택 실제 OCR 중 하나의 숫자 단서**를
요구했다. 숫자는 혼자서 양성 근거가 되지 않는다. 우주선의 실제4x 대안에 있는40%,
WINNER/MACHUJA의 실제 숫자 인식과 원본 픽셀을 함께 쓰며 문구를 합치거나 고쳐 쓰지 않는다.
숫자를 전혀 읽지 못하는 이미지의 새 v5 검토는 수행하지 않는 한계가 있다.

이미지 대상은 미해결 외부 링크 PNG 중 높이96이하·가로세로비3이상이다. 어느 실제 OCR
읽기에서든 공공안내나 같은 DOM 문구가 확인되면 제외한다. 기존 FP32 문자 backbone과
동일한 고정 revision의 vision encoder를 재사용하고 실제 픽셀+선택한 실제 OCR을 비교한다.
`image-ad-embedding-v2`는20기본 참조에 교육 수강 패키지/게임 아이템 정상 설명2개를
더한다. 실제 영상 margin>=0이면서 seed1701로 RGB 픽셀 배치를 섞은 대조의 margin<0일
때만 `image-only-ad-v5-image-review`로 통과한다. 이 대조는 픽셀 배치의 기여를 보이며
문자 해독이나 법적 불법성을 증명하지 않는다. 추가 이미지 클래스는 문자 경로에 섞지 않았다.

이미지 두 forward의 요청 예산은 합계16초, 기존 문자/OCR은8초이며 전체 마감은 유지한다.
동일한 직렬 OCR 자식 프로세스가 중단/시간초과 시 종료된다. TS와 Rust가 유한 점수,
margin 계산/대조 조건, 모델 revision, 이미지 SHA와 assetId 연결을 검증한다.
화면과 보고서는 `이미지 기반 검토 필요`라고 표시하고 실제 OCR과 이미지 추론을 구분한다.
새 encoder 데이터671,026,176B와 graph121,253B를 SHA 고정했다. 새 Python/OCR 런타임,
모델 재학습, 임계값 완화, 능동 광고주 탐색, 점검 중 다운로드/외부 AI 전송은 없다.
