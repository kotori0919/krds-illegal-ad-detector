# 교육 광고 의미 비교 개선과 남은 OCR 누락 진단

2026-10-21, `dev/bootstrap` / HEAD `56fd3563e031ef1850e88b4fdac0c39ead08eea5`의
미커밋 변경이다. 이전 교육 광고 오탐2건은 비교 문장에 교육 상품 문맥이 없던 문제를
수정했다. 남은 우주선/WINNER/MACHUJA3건도 실제 픽셀·검출 영역·CTC까지 진단했으나,
다른 광고를 손상시키지 않는 제품 수정은 확보하지 못했다. 세 누락 해결을 주장하지 않는다.
Windows 검증은 계속 보류했다.

## 실제 원인과 제품 변경

두 정상 광고는 해커스 토익 무료교재와 전기기사300% 환급이다. 이전 점검의 실제 OCR은
각각 `토익/토익점수상승/료배포`, `자격증/전기기사/환급반`을 포함했다. 작은 PNG용
대안 OCR을 시도한 사례가 아니었다. 단순 오타 교정이나 OCR 예산 확대가 이 두 건의
직접 수정은 아니다. 원문과 실제 정답을 분리해 보관하고 같은 고정 모델로 비교했다.

기존 비교 대상은 쇼핑·온라인게임·공공안내·도서관이었고 유료 교육, 무료 교재, 수강료
환급 문맥이 빠져 있었다. 두 원문의 가장 가까운 양성 설명은 모두 스포츠 토토 설명이었다.
이전 positive/negative cosine은 `.731672/.715117`, `.706305/.703462`였다.
정상적인 외국어 학습/교재/시험 강의 환급을 설명하는3개 문장을 추가하면 임계값0과
같은 원문/벡터를 유지하면서 정상 비교 설명이 가까워진다. 개발 단계에서 두 margin은
`+.016555 -> -.006159`, `+.002843 -> -.013640`으로 바뀌었다.

모델·FP32·prefix·양성 설명8개·기존 음성 설명8개·0 기준은 유지했다. **교육 키워드를
발견하면 제외하는 규칙이나 광고주 허용목록을 추가하지 않았다.** `policy.json`은 음성
설명3개가 늘어난 총19개이고 새 근거는 `text-ad-embedding-v2`로 식별한다. TS/Rust가
저장된 v1과 새 v2를 모두 읽는다. 실제 OCR/선택 원문/직접 규칙 양성/기존 공공안내 제외,
공식 JSON, 이미지·GIF·시간 예산은 그대로다. OCR/worker/scan 소스의 baseline SHA 동일을
읽기 전용 검토로 확인했다. 모델 파일·의존성·Windows 자산을 추가하지 않았다.

개발 비교에서 수강료 환급을 넓게 서술한 한글 문장을 무조건 추가하면 기존 양성의
실제 원문6개가 음성 쪽으로 뒤집혔다. 이 문장은 채택하지 않았다. 선택한3개 설명은
기존 양성의 primary/alternative 의미 판정을 보존했다. 교육 문구와 실제 카지노/입금
제안을 함께 넣은 진단 텍스트는 여전히 양성이다. 사람이 깨끗하게 전사한 문장은 원인
분석용으로만 분리했고 제품 OCR이나 실제 광고 성적에 넣지 않았다. 새 자료의 점수를
보기 전에 정책과 프로토콜을 동결했다. 알려진 오탐은 이제 개발/회귀 자료다.

## 세 누락의 인과 분석과 기각한 수정

세 입력은 같은 MoneyToday600×337 보도 사진의147×40 실제 크롭이다. 높은 해상도
원본을 새로 얻거나 업스케일 결과를 실제 증거로 꾸미지 않았다.

- 우주선: 검출 영역의 세로 여백으로 원래 작은 글자가 recognizer에서 더 작아졌다.
  같은 detector component/가중치를 유지하고 crop `(54,9,85,21)`의 세로 확장만
  줄여 `(54,13,85,13)`으로 만들면 `첫출전40%`가 실제 `첫충전 40%`로 복구된다.
  CTC는 출/충 `.723/.159 -> .421/.526`이다. 잘못 읽은 줄도 confidence가 높아
  임계값을 낮추는 방식으로 해결되지 않는다. 복구된 문구도 고정 의미 모델에서
  margin이 음수였다. 문구 복구와 최종 탐지를 구분한다.
- WINNER: 스타일 로고가 검출 영역에 잡히지 않는다. 4배 대안은 백분율과 숫자표를
  읽지만 광고 종류/제안 문구가 없고 숫자 전용 OCR은 현재 의미 보조 자격을 얻지 않는다.
  이 안전 조건을 풀어 숫자 할인 광고를 양성으로 만들지 않았다.
- MACHUJA: 브랜드는 이미 정확히 읽는다. 중요한4~6px 한글 문구가 깨지거나
  거부된다. 브랜드만 인식했다고 도박 광고 탐지에 성공한 것으로 계산하지 않는다.

세로 확장 축소를 기존17개에 적용하면 미라클의 `SPORTS& CASNO`, 다른 실제 광고의
카지노·가입코드·페이백 문구가 손상됐다. 고친 우주선만 예외로 적용하거나 OCR 문자를
사후 교정하지 않았고 전역 교체도 기각했다. 첫충전 양성 설명을 늘리는 실험은 교육
오탐을 재발시키고, 넓은 교육 설명을 함께 늘려도 일부 양성을 잃어 채택하지 않았다.
제품 OCR은 이전과 같다. 이 실험은 현재 가중치/크롭 경로의 한계를 보여주며 모든 OCR이
원리적으로 불가능하다는 증명은 아니다. 원본 배너 또는 더 적합한 인식기의 별도 검증이
필요하다. 상세 crop/모든 거부 줄/CTC/17개 회귀는 `ocr-diagnosis/README.md`와 JSON이다.
